# Data Directory & Provenance Guide

This directory holds the raw and processed datasets for the **MPLAD AI Risk & Anomaly Intelligence System (SIH26102)**.

---

## 📂 Directory Structure

```
data/
├── raw/                      # Raw MPLADS CSV files downloaded from official MoSPI portal
│   ├── mplads_mp_summary_2026-08-28.csv
│   ├── mplads_recommended_works_2026-08-28.csv
│   ├── mplads_completed_works_2026-08-28.csv
│   └── mplads_expenditures_2026-08-28.csv
│
├── processed/                # Generated by data pipeline (reproducible & indexed)
│   ├── mplads_intelligence.db   # High-speed SQLite database with B-Tree indices
│   ├── data_validation_report.json
│   └── match_report.json
│
└── profiling/                # Schema definitions and data quality summaries
```

---

## ⚡ How to Populate & Seed the Database

Once the raw CSV files are placed in `data/raw/` (or `dataset/`), run the automated pipeline from the root directory:

```bash
# 1. Run full data pipeline (Clean, Match, Feature Extraction, Scoring, Database Seeding)
python -m backend.data_pipeline.seed_db

# 2. Train the Unsupervised Isolation Forest Machine Learning Model
python -m backend.app.ml.train_model
```

The database `data/processed/mplads_intelligence.db` and the trained model in `ml_models/` will be generated automatically.
